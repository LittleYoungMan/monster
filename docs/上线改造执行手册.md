# 上线改造执行手册（可续跑）

更新时间：2026-02-19  
维护原则：本文件作为唯一执行面板；新窗口必须先读本文件再动代码，避免重复分析。

## 1. 目标与硬指标

- 最终目标：项目达到可商业上线的可玩质量。
- 关卡目标：单角色通关率控制在 5%-10%。
- 已确认机制约束：
  - 每角色默认 6 把武器槽。
  - 5/10/15/20 分钟刷新 Boss，且难度有明显阶跃。
  - 双经济系统：金币 + 矿石。
  - 商店/工坊刷新机制以 `docs/base.md` 为准。

## 2. 当前基线结论（不是报错视角）

## 2.1 可玩性断点

- 生存曲线失衡（玩家容错低、怪物成长陡）：
  - 角色 Health 分布：5 / 10 / 25（min/med/max）
  - 怪物伤害分钟加权均值：0m=4.78, 5m=15.05, 10m=25.54, 15m=36.00
  - 怪物 HP 分钟加权均值：0m=188.2, 5m=529.3, 10m=986.5, 15m=1451
- 交互打断严重：
  - 商店门/工坊门默认自动进入（强制打断战斗节奏）。
- 角色 Spec 落地不足：
  - `parse_character_spec` 仅覆盖部分模板，复杂句式未完整落地。
- UI 商用品质不足：
  - 页面虽可显示，但层级、尺寸、交互节奏与战斗流程耦合不合理。
